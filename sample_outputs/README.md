# Sample outputs

These files are generated by the batch command in the repository README using two student-recorded test turns and Gnani STT/TTS. `turns.json` and `turns.csv` include the recognized transcript, the agent's unedited reply, retrieved source sections, decision, tool calls, and processing status. `audio/` contains the corresponding generated spoken replies.

The original input recordings are intentionally excluded. To process your own audio, put WAV, FLAC, OGG, or AIFF turns in an `input_audio/` folder and run the documented command with your own Gnani API key and extracted dataset path.

# ZentroMart VoiceOps capstone

This repository implements the four-step VoiceOps brief: prompt-only baseline, document-grounded RAG, stateful tool-using support conversations, and Gnani-only speech input/output. The attached W3D5 adapter-evaluation notebook is a course exercise, not this chatbot; this project reuses its general RAG/evaluation ideas without its event-extraction adapter.

## Public repository

Public GitHub repository: https://github.com/manga-pannel-130/ZentroMart-AI-Support

Do not publish the course dataset, recorded input audio, `.env`, model caches, or generated personal data. The checked-in `sample_outputs/` contains generated turn records and Gnani reply audio; the source recordings are excluded.

## Requirements and setup

- Python 3.10-3.12 (Python 3.11 recommended)
- A copy of the provided synthetic capstone dataset extracted outside this repository. The dataset is intentionally not included in this submission package.
- Your own Gnani API key for voice. Create a local `.env` from `.env.example`; never commit the filled file.
- Internet access for the first download of the embedding and LLM checkpoints. The default Qwen2.5-1.5B model gives stronger instruction following than the capstone's original 0.5B model; on CPU it needs several GB of memory and may respond more slowly. A GPU helps.

Install from the repository root:

```bash
python -m venv .venv
# Windows PowerShell
.venv\Scripts\Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
```

Copy `.env.example` to `.env` and add your own `GNANI_API_KEY`. In the commands below, replace the dataset path with the directory where you extracted the official dataset ZIP. It must contain `kb/`, `data/`, `practice/`, and `tools/`.

## Required batch run command

Put the provided test audio files in `input_audio/`. Each file is one customer turn; name follow-up files `conversation_turn_01.wav`, `conversation_turn_02.wav`, etc. to retain conversation state. Supported input formats are WAV, FLAC, OGG, and AIFF. Use an explicit Gnani STT language code; `en-IN` accepts mixed English/Hindi.

```bash
python run.py --audio-dir input_audio --output-dir sample_outputs --data-dir "C:/path/to/Capstone_Project_Dataset_FTTT_2026" --stt-language en-IN --tts-language auto
```

For example, in PowerShell, use the same command with the dataset's actual Windows path. The command processes all supported files recursively and creates `sample_outputs/turns.json`, `turns.csv`, and one Gnani-generated WAV answer per successfully processed audio turn under `sample_outputs/audio/`. Every record includes the transcript, unedited agent reply, retrieved section IDs, decision, tool calls, and processing status. The transcript is the ASR result; the answer is generated by the agent. Failures are retained as rows with an error status.

The batch command requires your own Gnani key for both STT and TTS. It does not fall back to another speech provider. It uses Gnani's Realtime STT and TTS SDKs and explicitly selects `timbre-v2.5` by default. The client normalizes source clips locally before sending them to Gnani. See Gnani's [STT Realtime docs](https://docs.gnani.ai/api/STT/stt-websocket) and [TTS Realtime docs](https://docs.gnani.ai/api/TTS/tts-websocket).

## Local text demo

The app loads `.env` and automatically checks the project folder and the common `Desktop/Projects/zentromart-capstone-submission` location for the dataset. If you extracted the dataset elsewhere, set its root before launching Streamlit:

```powershell
$env:ZENTROMART_DATA_DIR = "C:\path\to\Capstone_Project_Dataset_FTTT_2026"
python -m streamlit run src/app.py
```

The text demo works without Gnani credentials. For voice input, record a clip, select **Transcribe recording**, review or edit the transcript, then select **Send voice message**. This explicit flow prevents duplicate transcription requests during Streamlit reruns. Replies are shown as text and spoken with Gnani TTS by default when GNANI_API_KEY is configured; turn off “Speak replies with Gnani TTS” in the sidebar for text-only mode. The audio player appears with each assistant reply and attempts to play automatically; browser playback settings may require clicking Play. The large Qwen checkpoint is loaded on the first request that needs generated text, so initial page display does not wait for the 3 GB model download/load. Python dependencies are not installed by the Streamlit launch command. The report's Step 1/Step 2 scores were measured with Qwen2.5-0.5B-Instruct, not the current 1.5B runtime default.

## Evaluation commands

Run the required same-model Step 1 prompt-only vs Step 2 RAG comparison on all 52 visible practice questions:

```bash
# PowerShell: $env:ZENTROMART_DATA_DIR = "C:\path\to\Capstone_Project_Dataset_FTTT_2026"
# macOS/Linux: export ZENTROMART_DATA_DIR="/path/to/Capstone_Project_Dataset_FTTT_2026"
python src/evaluate_steps.py
```

Run retrieval diagnostics and generated-answer phrase checks:

```bash
python src/evaluate.py --top-k 5 --generate
```

Replay all 23 visible multi-turn practice conversations:

```bash
python src/evaluate_conversations.py
```

Validate the extracted data tables and joins:

```bash
python src/validate_dataset.py
```

These are visible development examples, not the organizers' unseen test. The script saves the actual answers and metrics under `evaluation/`; review misses and language-specific answers manually. Phrase matching is a heuristic, not a semantic correctness score. Never tune on the organizers' held-out audio/questions.

## What is in the package

- `run.py`: batch audio-to-text-to-agent-to-audio command.
- `src/zentro_agent.py`: RAG, product lookup, verified order flow, escalation, ticket calls.
- `src/gnani_voice.py`: local audio conversion, Gnani STT, spoken-answer formatting, Gnani TTS.
- `src/evaluate_steps.py`: Step 1 vs Step 2 practice comparison.
- `src/evaluate.py`, `src/evaluate_conversations.py`: retrieval and dialogue checks.
- `report.pdf`: concise project report (maximum four pages).
- `demo.mp4`: two-minute demo, added after recording with the student's own Gnani key.
- `sample_outputs/`: generated artifacts from the batch command.

Only synthetic course data should be used. The supplied order verifier and ticket tool are simulations, not production security or support systems. Never record another person without their written consent.
